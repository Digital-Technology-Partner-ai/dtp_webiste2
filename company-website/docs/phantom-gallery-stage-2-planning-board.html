Persona Journey Priorities

Connect these back to the existing persona-led journey diagram.

1. Expensive Googlers

Adoption Radar -> Foundry Floor -> Solution Engine

Strong commercial entry because the pain is visible: money has been spent but work has not changed.

2. Compliance Hostages

Command Centre -> Adoption Radar -> Leadership Suite

Reassurance, governance and senior confidence should appear before selling delivery.

3. Tyre-Kickers

Adoption Radar -> Delivery Path

Convert dabbling into one owned initiative with a number and a decision gate.

4. AI Evangelists

Foundry Floor -> Solution Engine -> Delivery Path

Channel energy into prioritisation, governance and practical implementation.

5. Agent Cowboys

Leadership Suite -> AI Agents -> Command Centre

Speak to ambition first, then introduce control, ROI visibility and operating-model thinking.

6. Doubting Thomas

Command Centre -> Adoption Radar -> Proof Vault

Avoid hype. Lead with proof, risk reduction and a narrow first step.
